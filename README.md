# とうじょうRMO ウェブサイト

兵庫県加東市 東条地域「とうじょうRMO（農村型地域運営組織）」の公式ウェブサイトです。
**岡本・森・南山の3地区**が連携し、①農用地保全 ②地域資源活用 ③生活支援 の3つで地域を守る取組を発信します。
ビルド不要の素の **HTML / CSS / JavaScript** で構成しており、そのままサーバーに置くだけで公開できます。

---

## 📁 ファイル構成

```
tojo-site/
├── index.html        … トップページ（ヒーロー＋RMOとは＋3つの活動＋お知らせ）
├── about.html        … RMOとは
├── solutions.html    … 3つの活動（農用地保全・地域資源活用・生活支援）
├── challenges.html   … 地域の課題
├── contact.html      … お問合せ（フォーム付き）
├── news.json         … お知らせデータ（ここを編集して更新）
├── style.css         … 全ページ共通スタイル（白／薄グレーベース）
├── common.js         … 下層ページ共通の動作
├── README.md         … このファイル
└── images/
    ├── hero1.jpg  hero2.jpg  hero3.jpg
```

## 📝 お知らせの更新方法

お知らせは `news.json` を編集するだけで更新できます。HTMLを触る必要はありません。

```json
[
  {
    "date": "2026-09-06",
    "category": "お知らせ",
    "title": "とうじょうRMO説明会を開催します。",
    "url": ""
  }
]
```

| 項目 | 説明 |
| --- | --- |
| `date` | 日付（`YYYY-MM-DD`）。新しいものを上に並べます。 |
| `category` | 分類ラベル（例：お知らせ / イベント / 活動報告）。 |
| `title` | 表示する見出し。 |
| `url` | リンク先。**空 `""` なら文字だけ**、URLを入れるとリンクになります。 |

各ブロックの間はカンマ `,` で区切り、末尾の項目にはカンマを付けません。

## 🖼 ヒーロー画像の差し替え

`images/` 内の `hero1.jpg` `hero2.jpg` `hero3.jpg` を、**同じファイル名**で上書きすれば差し替わります。
推奨サイズは横 1600〜1920px 程度。3枚が5秒ごとに自動で切り替わります。

---

## 💻 ローカルでの確認方法

お知らせ（`news.json`）は `fetch()` で読み込むため、**ダブルクリック（file://）では表示されません。**
簡易サーバーを立ててご確認ください。

```bash
cd tojo-site
python -m http.server 8000
# → http://localhost:8000 を開く
```

## 🚀 公開方法

`tojo-site` フォルダの中身を、そのままサーバー／ホスティングにアップロードします。
（`README.md` は開発者向け。実際のトップページは `index.html` です。）

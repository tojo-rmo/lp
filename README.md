# とうじょうRMO ウェブサイト

兵庫県加東市東条地域「とうじょうRMO」の公式ウェブサイトです。
ビルド不要の素の **HTML / CSS / JavaScript** で構成しており、そのままサーバーに置くだけで公開できます。

---

## 📁 ファイル構成

```
tojo-site/
├── index.html        … トップページ（ヒーロー＋RMOとは＋3つの活動＋お知らせ）
├── about.html        … RMOとは
├── solutions.html    … 3つの活動（農用地保全・地域資源活用・生活支援）
├── challenges.html   … 地域の課題
├── contact.html      … お問合せ（フォーム付き）
├── news.json         … お知らせデータ（ここを編集して更新）
├── style.css         … 全ページ共通スタイル
├── common.js         … 下層ページ共通の動作（メニュー等）
├── README.md         … このファイル
└── images/
    ├── hero1.jpg     … ヒーロー画像①
    ├── hero2.jpg     … ヒーロー画像②
    └── hero3.jpg     … ヒーロー画像③
```

## 📝 お知らせの更新方法

お知らせは `news.json` を編集するだけで更新できます。HTMLを触る必要はありません。

```json
[
  {
    "date": "2026-08-28",
    "category": "お知らせ",
    "title": "とうじょうRMO説明会を開催します（9/6 岡本公民館 集会室）。",
    "url": ""
  }
]
```

| 項目 | 説明 |
| --- | --- |
| `date` | 日付（`YYYY-MM-DD` 形式）。新しいものを上に並べます。 |
| `category` | 分類ラベル（例：お知らせ / イベント / 活動報告）。 |
| `title` | 表示する見出し。 |
| `url` | リンク先。**空 `""` なら文字だけ**、URLを入れるとリンクになります。 |

### 追加するときは
1. `news.json` を開く
2. いちばん上の `{ … }` ブロックをコピーして、内容を書き換える
3. 各ブロックの間は **カンマ `,`** で区切る（末尾の項目にはカンマを付けない）
4. 保存してアップロード

> ⚠️ カンマの付け忘れ・付けすぎがあると表示されません。心配な場合は [JSONLint](https://jsonlint.com/) などで書式チェックできます。

## 🖼 ヒーロー画像の差し替え

`images/` フォルダ内の `hero1.jpg` `hero2.jpg` `hero3.jpg` を、**同じファイル名**で上書きすれば差し替わります。

- 推奨サイズ：横 1600〜1920px 程度の横長画像
- 3枚が5秒ごとに自動で切り替わります（下部のドットで手動切替も可能）

## 🔧 コンテンツページの追加方法

1. 既存のページ（例：`about.html`）をコピーして `xxx.html` を作成し、中身を編集
2. 各ページ共通の `<nav class="nav-links">` とフッターの `Contents` に、リンクを1行追加
   ```html
   <a href="xxx.html">新しいページ名</a>
   ```
3. トップページ `index.html` の「くわしく知る」カードにも、必要に応じて追加

外部サイトへのリンクにしたい場合は、`href` を外部URLに変えるだけでOKです。

## 💻 ローカルでの確認方法

お知らせ（`news.json`）は `fetch()` で読み込むため、**ファイルをダブルクリック（file://）した状態では表示されません。**
以下のいずれかの方法で、簡易サーバーを立てて確認してください。

### Python の場合
```bash
cd tojo-site
python -m http.server 8000
```
→ ブラウザで `http://localhost:8000` を開く

### Node.js の場合
```bash
cd tojo-site
npx serve
```

## 🚀 公開方法

サーバーやホスティングに、`tojo-site` フォルダの中身を**そのままアップロード**するだけです。

- **GitHub Pages**：リポジトリに配置し、Settings → Pages で公開ブランチを指定
- **レンタルサーバー等**：`index.html` が公開ディレクトリの直下に来るように配置

> `README.md` は開発者向けの説明ファイルです。実際に表示されるトップページは `index.html` です。
